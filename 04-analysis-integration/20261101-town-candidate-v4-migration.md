使用者目標是新角色完成教學後進入各職業城鎮。

提出反證，並辨識6001有廣場／建築、7001有海岸聚落／碼頭。

新版將盜賊7001、武道家6001列為**重建設計候選**，替換已被形態反證的目的圖；
這一步只證目的地具有聚落地標，尚未證明原服職業／地名配對。
尤其6001的原始職業綁定與生活講義的冰原描述仍不一致，不能稱已還原瑪賽。
版本線索、當前Client實際呈現及同版Server來源仍需繼續核對。

## 內容升級與資料保存契約

Profile升為`isolated-tutorial-route-candidate-v4`，新產生內容使用新版路線。
舊模板生成邏輯凍結，可重現v3；先前v1相機及v2摩斯升級仍依原模板比對，
不能因新版目的圖改變而拒絕原本可升級的保存設定。

完整教學入口對v3只在整份JSON與同Client素材產生的舊模板逐欄一致時升級：

1. 先驗schema／重複key，再比對完整舊模板。
2. 原檔獨立備份成功後，以唯一暫存檔原子替換。
3. 自訂v3拒絕覆寫，備份失敗保留原檔；已是v4不重寫、不重新產生。
4. 新設定同時保留1001與3001的相同MAP identity／revision／出生設定，僅名稱
   明示舊野外／地城，不再當畢業目的地。其餘三職、學校與戰鬥資料不改。
5. 不更新DB、帳號、Admin key、職業、教學里程碑、已提交角色位置或畢業事件。

保留舊MAP使既有位置仍有catalog項目，**不表示自動把舊畢業角色搬到新城市**。
已保存於1001／3001者保留原位置；重新安置或在舊圖提供正式出口是另一項待辦，
不得為測試通過而清空角色、回填里程碑或直接改其座標。
新畢業使用更新後的目的地／規則版本；已發出的舊對話／傳送仍須沿既有
Server身分及規則校驗，不接受Client指定任意城市。

## 驗證及實機界線

12項Python設定升級測試包含先前相機、摩斯及新增城鎮四項保護，全部通過。
另以實際素材驗證凍結生成器與現有v3完全相同、舊MAP identity保留、學校／
講師／訓練政策不變。從使用者保存設定複製一份執行完整升級鏈，副本升為v4，
原設定逐byte不變；本輪未更新使用者正在測試的環境。

新版實際素材五職業TCP全部通過：C02／C04、歡迎、入學、講義／選職、C0E與
C13普攻、死亡重生、畢業載圖及學校／目的地重登；每socket ordinal亦檢查。
盜賊確認載入7001，武道家6001；source profile SHA與每職結果記入機讀索引。
此結果僅證新候選路線可載入、教學交易及重登位置／職業，不證原版城鎮身份或原生GUI。
