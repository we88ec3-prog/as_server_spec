# 原生傳送入口、提示文字與目的地授權

本輪回應使用者「左側地圖藍點及地面特殊游標就是切圖入口」的回報，將入口來源追到實際 Client 資源與 native consumer。這解決**入口在哪裡、為何換游標**；沒有將尚未恢復的原服路線假稱已解析。能力窗實機測試仍獨立等待，未因此要求再次重啟或改動玩家進度。

## 游標與小地圖：與 metadata 分開

原件 EXE SHA256 `db3df616f68b9f32163abc4b88de9d310562b2ddfe955aaa5ba7fcff729e1145`，REA/Ghidra12.1.4。

- `0x4c0920` hover hit-test 得到 tileXY，呼叫 `0x4b2ce0` 檢查輔助 grid。非零時選 **cursor5**；若該 tile 有 Server 提示文字則顯示。這是原生游標切換的直接分支；使用者所見藍點／游標是人工觀察，沒有冒稱本輪已另取 runtime 錄影。
- `0x4d1080` 另透過 `0x4b2d00` 選小地圖繪圖 anchor。條件為「當格有標記，NW、N、NE、W 均無標記」。**不是任意八鄰接群只畫一點的演算法**；U形反例可同一群有兩個北側anchor。本輪表格的分組只是分析方便，不能當 native 入口 ID 或傳送配對。
- `MinimapLocation` 三整數 metadata 是另外的標記來源；第三欄1/2/3參與顏色選擇，沒有證明它是 destination map。先前只查 MAP尾段及此 metadata 不足以解釋所有入口，已由本輪 Basic slot24 補正。
- native 還以 `0x556aa0` 掃描角色附近 dx/dy=-5..5 的11×11格。`0x4bf4c0` 的一條呼叫路徑依結果顯示 BasicString491 的禁止做生意訊息，另一分支建構 `0x5770f0`（C17）。這是近入口擺攤限制的證據，**不能把11×11半徑當成換圖觸發範圍**。

## S07 kind13：座標標籤，並非目的地指令

`0x4f17c0` 的 kind13 分支把 rowXY 及文字交 `0x4c0640`。後者維護 `(i16x,i16y,UTF16 text[256])` 的本地記錄，stride0x204；相同 XY 已存在時直接返回。`0x4b97e0` 依精確 XY 尋找名稱，供 hover 使用。

Server 已有 S07 kind13 的 string8 CP950 codec，不需要另造一種「Portal packet」。若未來配置入口名稱，需針對希望可 hover 的**每個入口格**配置標籤；只給小地圖anchor一個名稱不能保證其餘入口格也查得到。不能依標籤文字直接授權換圖，也不能聲稱送出名稱就創建了本地 portal grid 或恢復原服配對。

相同XY的重送可去重，但「重送不同文字是否覆寫」在此 receiver 是忽略，不能用作即時改名方法。跨圖清除與改名完整時序仍待驗證。本輪沒有將猜測的名稱或出口送到玩家 Client。

## Server 規劃：將入口事實與路由政策分開

本節為後續開發契約，**尚未新增走門自動切圖的 Host 接線**。現有招募員、學校、畢業與職業候選城鎮流程保持原狀。

1. 入口內容索引保留來源archive/member SHA、source map/ref revision、完整入口格集合與native marker規則；不儲存推測目的地。不能以map檔名數字相鄰、入口圖樣相同或圖塊相同推定回程。
2. 另外的已審核路由表須明示：RuleRevision、來源map/revision、觸發格集合、觸發方式（站上／交談／技能等）、目的map/revision、到達XY／面向、教學與職業條件、回程政策及證據來源。原版已證或重建設計必須分別標記。
3. 觸發格不能超出已審入口集合；目的地必須有SHA鎖定可載入內容與可站立落點。**不能把一個會越界或被阻擋的格當正常出生點**。本地某入口被tileflags阻擋的例外要先查觸發模型，不能擅自去掉碰撞位元。
4. 決策依已認證的帳號／角色、目前lease、Server已提交位置、來源revision及所需教學進度，Client不能任意傳入destination作授權。`MapGate`、`Skill`、`Npc`、`Admin`等origin是記錄來源，不是權限本身。
5. 路由決定後沿已實作的 `S15/S14(1) → C35精確map/checksum → 提交 → S04/S33/S08/S14(2)` 屏障；同一epoch重送不得重發獎或重寫首次進圖。斷線保留已提交進度，未提交不提前畢業。
6. 「教學結束」仍要求持久教學條件與正式配置目的圖C35提交，不是看到藍點、走近門、C6C Close或原始MAP尾段有記錄就算完成。

## 可重跑驗證與界限

私有索引工具支援指定新輸出檔，預設寫入 `workspace/anal-roy-temp`，禁止寫入原素材或覆蓋既有證據。四項合成測試涵蓋LE/signed row、缺漏／額外bytes、版本／筆數、負座標、找不到map、越界、重複及native marker與分析分組不可混同。原資料完整跑過，所有2840入口對494張MAP尺寸有效；不需要重新啟動使用者Server。

本輪沒有跑新的 Client GUI、沒有傳送玩家、沒有修改地圖或Server路由設定。入口索引的成功不是原版目的地已恢復，也不是五職業原版城鎮配對／多房教學已驗收。接續追查應針對能提供目的地的腳本／Server metadata／已審核路線證據，不再重複要求已有的Basic／Map原檔。
