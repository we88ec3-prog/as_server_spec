# 可見 NPC 點擊對話政策

2026-11-08。**直接使用者需求**：NPC只要目前畫面點得到就能觸發對話，取消原本兩格交談限制。本文件是新的重建Server操作政策，並非發現或驗證了原服交談距離；舊文件的切比雪夫距離<=2屬當時設計，現在被本政策取代。

## 適用對象及授權條件

五城TownNpcs、招募員Recruiter、就職指導CareerAdvisor、生活／戰鬥教學Lessons及傳送師Teleporter全部適用。點擊原有C43 type1/subtype0及正確物件ref後，必須同時滿足：

1. 角色已完成當前地圖C35載入，world lease仍有效。
2. NPC與角色、當前地圖fixture的map ref及內容revision完全相同。
3. Server目前確實已向該角色投影該NPC身份，不能只因知道固定ref就遙控對話。
4. NPC仍在當前800×600原生Client／MapPane的既有可見矩形中。沿用相機偏移及右／下邊界排除規則；不另加兩格、對稱半徑或直線距離門檻。

因此可見且已投影的五格外NPC可以直接點擊。剛走入視野但尚未投影的邊界NPC仍不可點；等既有投影流程送出S07／S1A後才可開介紹。這也不能用來推論其他解析度或Client版本的可見區域。

## 回覆、Dispose及舊context

開啟對話之後，所有仍有效的回覆與第一次Dispose都重新檢查同一套可見性及身份條件。離開視野、切圖、revision改變、session被替代或沒有已投影身份時拒絕，不從舊對話發放教學完成、選職結果或傳送。尤其教學TALK尚未Dispose時離開視野，不能補交Dispose來取得里程碑。

已完成Dispose及已關閉context的無副作用清理可沿用既有有界冪等處理；它不重新授予對話、交易或任務權限。偽造、不同NPC、已取代context仍不能產生效果。入學、選職、里程碑及畢業既有資格規則沒有被可見點擊跳過。

這項改動只影響NPC對話。普攻／技能射程、怪物命中、地圖碰撞、站位、商店或銀行交易Store均不改動。

## 驗證界線

新增以五類對話入口為維度的隔離wire矩陣，涵蓋五格外可見成功、隱藏拒絕、跨圖／revision拒絕、進視野尚未投影拒絕、出視野回覆／Dispose拒絕、偽造及舊context不產生效果；教學TALK後離開視野未產生里程碑。招募員跨圖／revision的不合法配置還會先在建構時被拒絕，測試保留該較早的限制。

2026-11-08獨立建置的原生wire整合回歸 **129項全數通過**，其中新增矩陣40種組合（五類入口×八種情境）；既有Town遠距拒絕測例已改為真正視野外，不再把五格外但可見的位置當作拒絕條件。`git diff --check`通過。

以上是合成Client peer及SQLite／封包測試，不是原Client滑鼠已成功點開的GUI驗收。未為此重啟使用者遊戲或Server，未改原始Client。
