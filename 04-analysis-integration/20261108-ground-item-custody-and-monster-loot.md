# 地面物品、拾取競爭與怪物個人掉落

後續狀態：[正式隊伍與權威獎勵](20261108-party-membership-and-authoritative-rewards.md)已取代本頁當時的 solo fallback／最後一擊 EXP；本頁保管及原生拾取契約仍適用。下文「正式隊伍待接」是這份較早增量的歷史範圍，不能當目前仍未實作的判定；原生 GUI 仍各自待測。

目標來源為使用者要求直接開發完整 Server 並同步公開分析。以下交易結構、數值及圖像對照屬重建設計；原生操作及呈現依據見[REA 分析](20261108-native-ground-drop-pickup-and-object-resync.md)。原生 GUI 尚待驗收，不以合成或 TCP 測試替代。

## 原生入口

| 入口 | Client body | Server 權威處理與投影 |
|---|---|---|
| C08 丟棄 | kind=1、背包格位、u8 數量 | 核對已投影實例／版本、背包版本、生命及位置，同交易轉為地面保管；剩餘以 S0F 更新，空格以 S10 清除，再送 S07 kind3 |
| C07 拾取 | BEu32 地面物件引用 | 無數量／XY／目標背包格；驗已見證明、完整租約、同圖版本、鄰近一格、權限與完整容量；S0F 更新背包、S0E 移除地面 |
| C0C 重同步 | BEu32 缺失物件引用 | 只重投影當前合法可見物件；不拾取、不扣背包、不復生已領物品 |

C0C 先前只是疑似拾取入口，本輪原件 sender 已更正真正拾取為 C07。S07 kind3 的五個尾端 byte 未證為數量；本輪全 0，名稱附 `xN` 表示堆疊。已在 TCP 排隊的新舊地圖 C07／C08／C0C，在傳送載圖等待期間只作有界解析丟棄，不能更動舊圖資產。kind3 S07 原件會先移除同引用舊物件再重建，故可重送名稱／外觀而非新增第二份資產。

## 權威識別與交易

持久物品實例 ID、地面物件引用與已見能力是三種識別。引用由 Server 單調配置 `0x40000000..0x7fffffff`，不與目前自己、NPC、訓練怪引用混用；Client 引用、背包格、圖示都不能當持久 ID。能力 token 只在 Server 內部，綁完整 account／character／generation／connection、地圖版本、地面 ID／版本及實例版本，不能偽造為原生新增欄位。Host 另維持實際投影的可見集合。

背包、裝備、銀行及地面共用同一 canonical 物品列。整件丟下保留實例 ID、取得事件，將位置改為 Ground；部分丟棄則減原堆疊／增版本，以新 split ID 保存地面部分。落點只能是目前權威座標。Ground 的寬整數引用不能塞回 byte 背包格 DTO；一般背包／裝備／銀行讀取必須排除 Ground。

拾取按背包格位填相同定義／版本的未滿堆疊，剩餘需空格時保留地面實例 ID；全數合併可退役來源 ID，但 Taken 墓碑與收據須記錄來源、勝者、目標堆疊及數量變更。不能全部容納時整筆不變，不先部分拾取再丟失剩餘。裝備／銀行來源、數量 0／超過持有、死亡、失效租約及版本不符均不得先刪再補。

同交易核對 canonical 保管／實例版本及地面 Available／版本，提交背包增減／版本、Taken／領取者／時間、操作收據。兩玩家爭同一地面只能一人成功；Taken 引用重送不能再發物品。內部同操作 ID 同命令回原收據，異命令拒絕；C08 本身沒有全域操作 ID，不能宣稱任意相同 wire bytes 都能判定為舊重送。Host 應以已投影能力與 CAS 保護，不能用 bytes 雜湊永久封鎖合法重複操作。

## 保存及政策

地面物品預設永續，沒有無審計的到期刪除；斷線／重啟不清空。預設查詢 12 格、最多 256 候選，再依固定 Client 視窗投影；拾取為八方向最大座標差不超過 1。這是版本化重建界限，不是原服容量或到期時間。

| 持久紀錄 | 必要主鍵與內容 |
|---|---|
| 地面狀態 | 地面 ID／唯一引用；map／版本、XY、實例／定義／版本、數量、來源／保管角色、私人領取者、Available/Taken、版本及領取結果 |
| 引用配置器 | 全域下一引用；不得因重啟重用仍有效引用 |
| 操作收據 | 角色＋操作 ID；完整命令、結果及資產變更 |
| 固定政策 | 政策版本＋完整內容；同版內容改動拒絕 |
| 視圖能力 | 角色／generation／connection／地面 ID；token、地面與實例版本 |
| 怪物掉落意圖 | map／內容版本／出生點／生命序號唯一；貢獻、歸屬、機率抽值、交付或無掉落結果 |

新增到已有 SQLite 角色資料前先建立一致備份。本輪 World 輔助表檢查由 32 增為 38，並非原始遊戲資料庫版本；重啟不能重授物品或清除既有地面保管。

## 掉落與既有隊伍需求

**R-033 使用者需求仍完整保留**：最高總傷害隊伍得獎，全員各得完整 EXP、各自獨立判定掉寶，不以最後一擊決定、不代表每人必掉。

正式組隊收發／持久成員快照尚未接線。本輪只有明示的無組隊開發 fallback：每名角色視為獨立 solo party，依同一怪物生命的有效傷害總和選擇；同分採最早有效命中版本、再角色 ID。政策明記 RequireSoloRecipients、tie 及離線資格，日後有隊伍功能不能靜默繼續套最高個人。**本輪不代表 R-033 完成**；EXP 仍沿用既有最後一擊流程，完整隊伍經驗結算待整合。

開發預設 100% 機率產生一瓶 HP 藥水，供驗證掉落／拾取閉環，可版本化調整，並非原服表。普通攻擊與技能致死均在同一死亡交易建立意圖及私人地面，僅該角色可見／領取；預設離線勝者也保留待領結果。意圖保存全部貢獻、歸屬、抽值及 Created／NoDrop 等結果，重試不重新抽；引用耗盡須保留可追查未交付意圖，不能謊稱已送入背包。

## 驗證

最終完整 .NET 回歸 **691 項通過**，其中本輪新增核心 17 項、Host／圖源防護 2 項。核心涵蓋死亡讀取／拒絕變更、過期租約、實際跨圖舊能力拒絕、版本／政策內容衝突、丟棄／拾取及致死結算觸發器回滾、既有角色一次備份，以及普通攻擊／技能的最高傷害 solo 私人掉落、同分、離線資格、0%／同生命不重抽。另有 4 項獨立守恆 oracle 通過。

最終隔離 Host SHA256：`5bdb669b85fc6ded38ced9037eba6b5d1e2409ccb1ae567d6b4122b8c47a6536`。同版實際 TCP 的 8 項物品檢查與 4 項私人掉落檢查全部通過：無效數量／種類、部分丟棄、C0C 不拾取、雙玩家僅一提交且雙方移除投影、Taken 重送不增物品、堆疊合併、滿包不遺失、重登／獨立 Host 重啟保存，以及非受領者不可見／不可領私人結果、領取一次及不重複發放。

原生拖放／數量對話／點地面／背包滿提示、圖像及命中範圍仍待遊戲實測。獨立 TCP 此 fixture 未覆蓋的跨圖／距離／死亡已分別記錄核心測試證據，不能宣稱同一檢查已涵蓋所有層級。原始 EXE SHA256 仍為 `db3df616f68b9f32163abc4b88de9d310562b2ddfe955aaa5ba7fcff729e1145`，本輪未修改原件。
