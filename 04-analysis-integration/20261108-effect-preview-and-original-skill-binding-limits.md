# 特效預覽與原版技能對照的界線

2026-11-08。使用者回報目前魔法特效奇異，詢問能否從主程式判斷正常技能特效。本輪只檢視既有匯出與 Effect4 的六個有限候選，不更改技能綁定，也不把挑選外觀當作還原原版技能。

## 可以確定與仍然缺少的對照

本版 Client 有可解析的效果 runner、圖片、動作與播放／清理程式；因此不是找不到特效，也不是必須隨機選ID。已追通 S13 的 selector→EffectN.dat runner→YPF object，並有原件 duration／回邊／音效節點的檢查。4000的循環及4006的有限生命週期見 [更正契約](20261108-native-effect-lifecycle-correction.md)。

但 S62 是 Server 下發的技能格、名稱／命令、圖示、use mode及CastValue；S13另外指定這次動作的effect selector。**本輪已證S62沒有直接的effect selector欄位，不能由技能圖示或名稱推出S13該用哪個ID。** 原生S62 handler另查HelpString，再建立ActionEntry；本輪沒有取得一份含具名原版技能與S13 effect完整配對的可信原始表。HelpString、技能指令文字或圖示存在，也不等於已證該配對。

本輪六個 runner 的member名稱都是數字 `Effect04xxx.eff`，不是具名火球／冰箭；其已解析圖節點保存圖片key、時序、座標／條件及references，沒有因此得到一份具名技能目錄。這是選定資料的觀察，不代表整套資源所有位置都沒有名稱或metadata。原始Server資料、可識別技能的原服封包／畫面、或其他經核對的對照來源可補足；在沒有它們時保留未知。

## 六個有界離線預覽

已從既有原件解碼每候選的第一、中間、最後physical frame，親自檢視縮圖。所有候選皆在同一 Effect4.dat／effect04.ypf，hash沿用生命週期契約；此輪沒有增加外部聲音依賴。以下分類只是**離線外觀描述**，不是原服技能名稱或用途。

六個圖路徑均只有CreateEffectsAction→image，image references為空，沒有回邊及type7音效節點；完整YPF metadata有界檢查至data base。這只提供「有有限生命週期且可預覽的素材」子集，不能把它們都當作攻擊魔法。4006能自然結束，並不代表視覺適合既有重建法擊。

縮圖僅重現primary palette與透明mask，沒有native混色、座標變換、鏡頭、附著／飛行、runner運動及時序合成；亮度與最終畫面可能不同。physical frame亦不等於action播放序列。本輪沒有為了好看擅自增亮、改色或修改資源。實際圖片與解碼工具只留本地分析區；公開機讀檔僅含可重現metadata及SHA。

## 後續開發決策

應把兩件事分開完成：先根據圖路徑及原生清理確認可安全呈現，再由技能需求與實機外觀選擇明示重建的視覺綁定；有原始對照後才標成還原原版。尚未確認合適外觀時可明示停用通用特效，保留施放、傷害與資源功能，不默默輪換另一個未審素材。

本次六個預覽供選擇方向，沒有更新Host selector、沒有修改Client／素材，也沒有完成新的原生GUI驗收。原版具名魔法→effect的配對仍列待分析，不能因可播放素材而標成已完成。
