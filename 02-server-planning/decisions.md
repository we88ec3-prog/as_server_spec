# 架構決策索引

|ID|決策|狀態|理由／待決事項|
|---|---|---|---|
|ADR-001|共同規格與私有實作分開Git|採用|作者與其他人都依同一契約開發；不同remote與存取權限|
|ADR-002|模組化單體起步、邏輯分離gateway/world/admin|建議|現有證據與負載不足以支持先拆微服務；實作可不同|
|ADR-003|技術棧不作相容性規範|採用|Python/C#/Go/Rust等均可，只要行為與CT相容|
|ADR-004|Server權威與有序世界變更|採用|Client意圖不直接覆寫位置、資產與戰鬥結果|
|ADR-005|原服未知規則以自訂profile明示|採用|避免本機fallback被誤認官方規則|
|ADR-006|規格與合成向量的授權|待擁有人選定|不把私有Server或原遊戲素材一起授權|

新ADR模板：問題／相關R／選項／決策／證據或設計依據／影響PKT和SCN／遷移與回復／驗證方法。作者的語言、DB選擇等私有實作ADR放開發repo，不強迫其他實作採同一技術棧。
