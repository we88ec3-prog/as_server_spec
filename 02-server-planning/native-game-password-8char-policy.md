# 已由新版 4～8 字遊戲密碼規格取代

**2026-10-31 最新決策：遊戲帳號密碼改為 4～8 字**（不是恰好8字）。

本檔保留為舊連結導引，避免歷史報告失效。唯一有效的規則、管理員建帳／重設與未來修改 Client 的相容性規劃，請參閱 [native-game-password-4to8-policy.md](native-game-password-4to8-policy.md)。

此變更只屬 `as_server_spec` 規劃，`as_server_roy` 原先限制 10～128 字的程式碼仍需 DEV-030 修改。原版 `Asgard.exe` 未修改，Client E2E 尚未通過。
