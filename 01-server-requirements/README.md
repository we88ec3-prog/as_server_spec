# Server需求

需求是各實作共同的目標，不指定作者的資料庫表或程式語言。

|ID|系統|優先序|需求|驗收|目前基線|
|---|---|---|---|---|---|
|R-001|SYS-AUTH|P0|連線與版本協商|分段／合併 frame、版本拒絕、錯誤長度和逾時均有明確行為。|已知部分|
|R-002|SYS-AUTH|P0|登入與連線交接|密碼錯誤後可重試；交接憑證一次性、會過期、不能跨角色重用。|原型已驗收|
|R-003|SYS-CHAR|P0|創角及角色保存|符合客戶端合法性別／髮型／顏色範圍，兩階段建立失敗不得留下半成品。|所測選項已驗收|
|R-004|SYS-WORLD|P0|進圖及跨圖|初始化順序、載入確認、地圖失敗、切圖中斷及回復策略均有情境規格。|正常路徑已驗收|
|R-005|SYS-MOVE|P0|移動及同步|伺服器裁定位置、障礙與速度；步伐確認、轉向、序號環回及校正可重現。|確認已知；碰撞待分析|
|R-006|SYS-LOOK|P0|外觀與裝備顯示|髮型、髮色、衣服、染色、面向獨立；多人可見且重登一致。|部分實機；最新顯示修正待驗收|
|R-007|SYS-WORLD|P0|多人可見性|兩個原客戶端互相看見進入、移動、換裝、離開與斷線；不殘留幽靈物件。|待分析／開發|
|R-008|SYS-ITEM|P0|物品與背包|物品實例、堆疊、裝備槽、使用、脫裝與刪除均由伺服器驗證。|目前只有測試衣櫃|
|R-009|SYS-STATS|P1|角色數值|等級、HP/MP、屬性、裝備修正及客戶端狀態欄同步。|待分析|
|R-010|SYS-COMBAT|P1|戰鬥與死亡|命中／傷害／資源消耗／死亡／復活為可測試的權威狀態轉移。|待分析|
|R-011|SYS-SKILL|P1|技能與效果|目標、距離、施法、冷卻、持續效果、取消及異常狀態有清楚規則。|待分析|
|R-012|SYS-NPC|P1|怪物與NPC|生成、AI、仇恨、互動、掉落及重生；AI不阻塞網路迴圈。|待分析|
|R-013|SYS-QUEST|P2|對話與任務|對話選擇、任務狀態、條件與獎勵可保存；重送不得重複領獎。|待分析|
|R-014|SYS-ECONOMY|P2|金錢及交易|商店、玩家交易、倉庫及製作各有原子提交、取消與中斷測試。|功能範圍及原規則待確認|
|R-015|SYS-SOCIAL|P2|聊天及組隊|頻道、密語、組隊、權限和離線情境；公會依客戶端證據擴充。|待分析|
|R-016|SYS-CONTENT|P0|遊戲資料版本|資源存在與功能正確分開；地圖、物品、技能定義有版本、來源及校驗。|已有資源清單|
|R-017|SYS-PERSIST|P0|持久化及一致性|角色和資產變更有交易邊界；重啟、重送及失敗回復不複製物品或遺失已承諾交易。|單人位置／衣服已驗收|
|R-018|SYS-OPS|P0|管理及營運|管理操作身分、權限、稽核及限制與遊戲連線分離。|目前僅本機測試管理|
|R-019|SYS-OPS|P0|觀測與診斷|可追 session／場景／opcode／狀態；不記明文密碼、token或完整敏感封包。|已有最小 trace|
|R-020|SYS-OPS|P1|容量及可用性|先驗證2個客戶端，再設可量測負載目標；延遲、佇列、儲存耗時均有基線。|容量目標待量測|
|R-021|SYS-OPS|P1|安全與濫用控制|封包長度、速率、狀態、權限及伺服器權威檢查不得以信任客戶端取代。|待完善|
|R-022|SYS-AUDIO|P1|音樂與客戶端呈現|播放／停止與切圖順序可測；曲目對應未知時標本機設計。|聲音已驗收；原曲目對應未知|
|R-023|SYS-SPEC|P0|獨立實作相容性|不同語言的Server可只依共享規格與向量實作；不得依賴私有原始碼。|本次建立基線|
|R-024|SYS-SPEC|P0|共同規格及變更|本作者的私有實作與其他實作採同一規格版本、測試與偏差登錄。|本次建立基線|

P0為建立可靠相容核心的前置工作；P1為完整可玩循環；P2為內容與營運擴充。商店、製作、公會、PvP、郵件等細節須依Client證據及產品範圍決定，不能單憑MMORPG慣例認定原遊戲全部支援。容量、tick和部署平台先量測再承諾；目前不宣稱支持任何營運人數。
