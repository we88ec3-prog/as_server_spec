## 維護規則

- Fxx為功能ID，Fxx-yy為子功能ID，Fxx-yy-Tzz為細項ID。新增內容使用新ID，不重新編號或回收舊ID，避免人工備註對錯項。
- 之後更新先讀最新xlsx並保留人工編修。`initial-source-20261107.json`僅保存初版生成來源，不能直接覆寫之後的Excel內容。
- 未分析功能保留具體分析方向，不猜技能ID、NPC清單、職業數值及原服傳送目標。
- 郵件、製作、公會等是完整Server候選範圍，需先確認本版存在及要實作的範圍。銀行和商店有使用者舉例來源，具體原服規則仍待補證。
- 本輪開發中的衣櫃已有389項.NET回歸通過，含新衣櫃測例；HTTP/TCP及遊戲畫面尚待驗收，因此仍記開發中。私有實作程式不收進此目錄。
- 本表只計細項及驗收數，不把數量占比當作工時、完整遊戲完成率或交期。
